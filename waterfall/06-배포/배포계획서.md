# 배포 계획서 — MuDeal (Cloudflare Workers)

| 항목 | 내용 |
|---|---|
| 대상 서비스 | MuDeal MVP v1.0 |
| 대상 플랫폼 | Cloudflare Workers + Workers Static Assets + D1 + R2 + Cron Triggers |
| 진입점 | `worker/index.ts` (`wrangler.jsonc`) |

## 1. 최초 인프라 프로비저닝 (1회)

```bash
# 1. Cloudflare 로그인
npx wrangler login

# 2. D1 데이터베이스 생성 -> 출력된 database_id를 wrangler.jsonc에 반영
npx wrangler d1 create mudeal-db

# 3. 제보 증빙 이미지용 R2 버킷 생성
npx wrangler r2 bucket create mudeal-evidence

# 4. 원격 D1 스키마 마이그레이션 적용 (migrations/에는 DDL만 포함, seed.sql 제외됨)
npx wrangler d1 migrations apply mudeal-db --remote
```

## 2. 운영 Secrets 설정

```bash
npx wrangler secret put JWT_SECRET          # 32자 이상 고엔트로피 랜덤 문자열
npx wrangler secret put ADMIN_OAUTH_EMAILS  # 쉼표 구분 관리자 이메일
npx wrangler secret put KOPIS_API_KEY       # KOPIS 오픈 API 인증키
npx wrangler secret put KAKAO_CLIENT_ID
npx wrangler secret put KAKAO_CLIENT_SECRET
npx wrangler secret put GOOGLE_CLIENT_ID
npx wrangler secret put GOOGLE_CLIENT_SECRET
npx wrangler secret put GEMINI_API_KEY      # 공지 이미지 Vision/OCR용
```

## 3. 빌드 및 배포

```bash
npm ci
npm run typecheck
npm test
npm run build
npx wrangler deploy
```

## 4. 배포 후 점검 및 롤백

1. `https://<도메인>/` 및 `/api/v1/home` `200 OK` 확인
2. 관리자 소셜 로그인 후 `/admin/deals`에서 `KOPIS 수동 재수집` 실행 → 공연·배우 적재 확인
3. Cloudflare Dashboard → Workers → Triggers에서 Cron 3종(`*/15 * * * *`, `0 16 * * *`, `0 */6 * * *`) 활성 확인
4. 장애 시 `npx wrangler rollback`으로 직전 버전 즉시 복구, D1 데이터 이상 시 `wrangler d1 time-travel restore`로 시점 복구
