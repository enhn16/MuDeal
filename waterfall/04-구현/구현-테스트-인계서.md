| --- | --- |
| 프로젝트·릴리스 | MuDeal / MVP v1.0 |

| 런타임·프레임워크 | Node.js 24, Next.js App Router (`vinext 1.4.6`), Vite 8, Tailwind CSS 4, Drizzle ORM, Cloudflare Workers (`wrangler 4`) + D1 + R2 + Cron |

## 1. 구현 범위 요약

- **전체 화면 (`SCR-01` ~ `SCR-10`)**: `/`, `/search`, `/shows/[id]`, `/actors/[id]`, `/login`, `/reports/new`, `/my`, `/admin/reports`, `/admin/deals`, `/admin/issues`
- **REST API (`/api/v1/*`)**: 공개 조회·비교·클릭/도움(9종), OAuth/세션(6종), 개인화 `/me/*`(13종), 회원 제보·R2 업로드·오류 신고(3종), 관리자 검수·딜·배우병합·오류·동기화·OCR·큐레이션(16종)
- **비동기 배치 & Cron (`worker/index.ts`)**: `*/15 * * * *`(자동 마감), `0 16 * * *`(KOPIS 일일 동기화 01:00 KST), `0 */6 * * *`(1차 채널 저빈도 수집 + Vision/OCR 일일 상한 처리)
- **DB 스키마 (`src/db/schema.ts`)**: D1 19개 테이블 + `migrations/0000_curved_mystique.sql` + 로컬 시드(`src/db/seed*.sql`)

## 2. 재현 가능한 빌드·실행 명령

```bash
npm install
npm run db:migrate:local
npm run db:seed:local
npx wrangler d1 execute mudeal-db --local --file=src/db/seed-personal.sql
npx wrangler d1 execute mudeal-db --local --file=src/db/seed-admin.sql
npm run typecheck
npm test
npm run build
npm run dev   # http://localhost:5173
```

## 3. 남은 운영 사전 작업 (배포 전 필수)

| 항목 | 설명 |
| --- | --- |
| Cloudflare D1 / R2 프로비저닝 | `wrangler d1 create mudeal-db`, `wrangler r2 bucket create mudeal-evidence` 후 `wrangler.jsonc`의 `database_id` 교체 |
| Workers Secrets 등록 | `JWT_SECRET`, `KOPIS_API_KEY`, `KAKAO_CLIENT_ID`, `KAKAO_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `ADMIN_OAUTH_EMAILS`, `GEMINI_API_KEY` |
