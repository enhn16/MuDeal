## 1. 목적 및 테스트 범위

### 1.1 목적
Cloudflare Workers + D1 + R2 프로덕션 배포 전, MuDeal의 핵심 비즈니스 로직(할인율·KST 경계·3분류 필터·4축 검색), 보안·권한(카카오 OAuth·`ADMIN_KAKAO_IDS`·`JWT_SECRET` Fail-Fast·보안 헤더·R2 경로 검증), 개인화(찜·팔로우·캘린더·회원탈퇴), 외부 연동(KOPIS 증분 수집·만료 배치) 및 SEO/법적 페이지를 체계적으로 검증한다.

### 1.2 테스트 대상 범위
- **포함**:
  - 공개 탐색(`/`, `/search`, `/shows/[id]`, `/actors/[id]`, `/terms`, `/privacy`, `/robots.txt`, `/sitemap.xml`)
  - 인증·인가(`/login`, 카카오 OAuth, Refresh 회전, `ADMIN_KAKAO_IDS` 자동 승격, `401`/`403` RBAC, `DELETE /api/v1/me` 회원탈퇴)
  - 개인화(`/my` 스토리 바·내 캘린더·저장한 소식·내가 제보한 내역·최하단 회원 탈퇴)
  - 회원 제보 & 어드민(`/reports/new`, R2 업로드·증빙 미리보기, 통합 검수, 딜 CRUD, OCR 재시도, 오류 신고)
  - 동기화·배치(KOPIS 증분 수집·공연장 캐시·50 subrequest 한도, 마감 처리, Vision/OCR JSON 스키마)
- **제외**: 자체 결제·발권(`EX-001`), 일반 티켓오픈(`TICKET_OPEN` 제거), 운영 실도메인 부하 테스트(배포 직후 별도 측정).

## 2. 테스트 레벨 및 전략

| 레벨 | 도구 / 환경 | 범위 | 합격 기준 |
|---|---|---|---|
| **정적 검증** | `tsc --noEmit` | 전체 TypeScript 코드 (`src/`, `worker/`) | 오류 0건 |
| **단위 테스트** | Vitest 5.1 (`npm test`) | 6개 테스트 스위트 (KST·가격·URL·4축 검색·인증/RBAC·탈퇴·제보·KOPIS/OCR) | 전체 케이스 100% 통과 |
| **빌드 검증** | `vite build` (`vinext` + `@cloudflare/vite-plugin`) | RSC + SSR + Client + Worker Cron 번들 | 0 에러, 전 라우트 생성 |
| **통합·시스템 E2E** | Node QA 스크립트 (`http://localhost:5173` + 로컬 D1/R2 + `.dev.vars`) | 공개/인증/어드민 API·페이지, 보안 헤더, 404 복구, R2 경로 차단, KOPIS 실키 API 연동 | P0/P1 결함 0건, 핵심 TC 100% 통과 |
| **수동 UAT** | 데스크톱 브라우저 (`http://localhost:5173`) | 카카오 실제 로그인 → 약관 동의 → MY → ADMIN 진입 → 카드 정렬·토스 UX 확인 | 주요 플로우 이상 없음 |

## 3. 출시 종료 기준 (Exit Criteria)

1. `npm run typecheck`, `npm test`, `npm run build` 모두 종료 코드 `0`
2. P0(치명)·P1(주요) 미해결 결함 **0건**
3. `.env` / `.dev.vars` Git 제외 확인 (`git check-ignore`), 운영 `JWT_SECRET` Fail-Fast 테스트 통과
4. 법적 필수 페이지(`/terms`, `/privacy`) 및 회원탈퇴(`DELETE /api/v1/me`) 정상 동작 확인
5. KOPIS 실인증키 기반 전국 뮤지컬 수집 성공 확인
